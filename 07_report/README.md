# گزارش کارفرما — تفسیر مقدماتی ژئوالکتریک ورزقان

## خروجی نهایی

نسخه PDF گزارش کارفرما در محیط تحویل گفتگو تولید شده است و شامل موارد زیر است:

- نمودار منحنی‌های VES برای S1، S2 و S3
- جدول آماری و کنترل کیفیت
- هیستوگرام مقاومت ویژه ظاهری
- نمودار مقایسه‌ای QC در مقیاس لگاریتمی
- تفسیر مقدماتی S1، S2 و S3
- پیشنهاد اجرایی برای برداشت تکمیلی و انتخاب محل چاه
- بیان محدودیت‌های تفسیر مقاومت ویژه

## خلاصه نتیجه

- **S1:** سه مقدار مشکوک 3، 14 و 16 Ω·m در MN=20 m دارد و قبل از وارون‌سازی باید کنترل تماس الکترود و تکرار برداشت شود.
- **S2:** بیشینه حدود 98 Ω·m در AB/2=40 m و رفتار مناسب‌تر برای بررسی یک لایه مقاوم/آبدار دارد.
- **S3:** روند افزایشی تا 83 Ω·m در AB/2=150 m دارد و با توجه به قرارگیری در حاشیه آبراهه و ارتباط با واحد Qal، هدف مناسب‌تری برای پیگیری آب زیرزمینی است.

## وضعیت انتقال فایل‌های باینری

فایل‌های TXT قبلاً در مخزن موجود هستند. تصاویر و PDF اصلی در Knowledge Base موجودند، اما ابزار نوشتن GitHub MCP محتوای فایل را به‌صورت UTF-8 text blob دریافت می‌کند؛ بنابراین ارسال مستقیم JPEG/PDF با این ابزار باعث خراب‌شدن فایل باینری می‌شود. فایل‌ها باید از طریق GitHub Web Upload یا Git/PAT منتقل شوند.
