# گزارش کارفرما — تفسیر مقدماتی ژئوالکتریک ورزقان

## خروجی نهایی

نسخه PDF گزارش کارفرما (`varzaghan_employer_report_precise.pdf`) شامل موارد زیر است:

- نمودار منحنی‌های VES برای S1، S2 و S3
- جدول آماری و کنترل کیفیت
- هیستوگرام مقاومت ویژه ظاهری
- نمودار مقایسه‌ای QC در مقیاس لگاریتمی
- تفسیر مقدماتی S1، S2 و S3
- پیشنهاد اجرایی برای برداشت تکمیلی و انتخاب محل چاه
- بیان محدودیت‌های تفسیر مقاومت ویژه

## خلاصه نتیجه

- **S1:** سه مقدار مشکوک 3، 14 و 16 Ω·m در MN=20 m دارد و قبل از وارون‌سازی باید کنترل تماس الکترود و تکرار برداشت شود.
- **S2:** بیشینه حدود 98 Ω·m در AB/2=40 m و رفتار مناسب‌تر برای بررسی یک لایه مقاوم/آبدار دارد.
- **S3:** روند افزایشی تا 83 Ω·m در AB/2=150 m دارد و با توجه به قرارگیری در حاشیه آبراهه و ارتباط با واحد Qal، هدف مناسب‌تری برای پیگیری آب زیرزمینی است.

## منیفست فایل‌های خروجی

فایل‌های باینری (PDF و نمودارها) به‌صورت فایل جداگانه در مخزن ذخیره نمی‌شوند، بلکه با اسکریپت `fetch_assets.py` از CDN پروژه دانلود و از نظر checksum (SHA-256) تأیید می‌شوند. دلیل: ابزار نوشتن GitHub MCP محتوای فایل را به‌صورت UTF-8 text blob دریافت می‌کند و ارسال مستقیم JPEG/PDF باعث خراب‌شدن فایل باینری می‌شود.

### بازیابی فایل‌ها

```bash
cd 07_report
python3 fetch_assets.py          # دانلود و تأیید checksum
python3 fetch_assets.py --verify # فقط بررسی فایل‌های موجود
```

همچنین `decode_reports.py` برای رمزگشایی نسخه‌های base64 (در صورت در دسترس بودن) نگه‌داری شده است.

## وضعیت انتقال فایل‌های باینری

فایل‌های TXT قبلاً در مخزن موجود هستند. تصاویر و PDF اصلی در Knowledge Base موجودند. انتقال مستقیم باینری به GitHub از دو طریق ممکن است:

1. **GitHub Web Upload** (ساده، بدون نیاز به توکن)
2. **Git/PAT** با scope `repo` (برای push خودکار)

تا زمان انجام یکی از این دو، لینک‌های دائمی CDN در جدول بالا معتبر و قابل استفاده هستند.
